📖 Manual de PantallaCast AI

🔐 Cómo otorgar permisos de pantalla

Cuando pulses Iniciar compartición, el navegador mostrará un cuadro de diálogo pidiéndote que elijas qué compartir.

  1. Selecciona Pantalla completa, una ventana específica, o una pestaña.
  2. Haz clic en Compartir para confirmar.
  3. Para detener, pulsa Detener compartición en esta aplicación o el botón que aparece en la barra del navegador.
💡 Consejo: Usar "Compartir una pestaña" es la opción más estable en Chrome y Edge.

🚫 Si el permiso fue denegado

Sigue estos pasos para restablecer el permiso:

  1. Haz clic en el candado (🔒) en la barra de dirección.
  2. Busca Acceso a la pantalla o Display capture.
  3. Cámbialo a Permitir y recarga la página.
⚠️ La captura de pantalla solo funciona en Chrome, Edge y Firefox de escritorio. No está disponible en iOS ni en la mayoría de navegadores móviles.

🔍 Cómo funciona el descubrimiento de dispositivos

Esta aplicación usa WebRTC para transmitir video directamente entre dos dispositivos (P2P), sin pasar el video por el servidor. Sin embargo, para iniciar esa conexión, los dos dispositivos necesitan intercambiar información de red a través de un servidor central. A eso se le llama señalización.

📋 Pasos para conectar dos dispositivos

  1. Ambos dispositivos deben estar en la misma red Wi-Fi o LAN.
  2. En el dispositivo Emisor: abre http://[IP-del-servidor]:3000 y pulsa Iniciar compartición.
  3. En el dispositivo Receptor: abre http://[IP-del-servidor]:3000/viewer.html y pulsa Conectar.
  4. El servidor de señalización intercambia la oferta/respuesta WebRTC automáticamente.
  5. Una vez establecida la conexión P2P, el video fluye directamente entre dispositivos.
🌐 Para encontrar la IP de tu servidor, ejecuta ipconfig (Windows) o ifconfig / ip addr (Linux/Mac) en la terminal.

🤖 Análisis de IA

Cada pocos segundos, la aplicación captura un fotograma de la pantalla, lo convierte a imagen y lo envía al backend. El backend lo reenvía a Claude Vision (claude-sonnet-4-20250514), que devuelve una descripción en tiempo real visible en el panel derecho.

🔧 Problemas comunes y soluciones

❌ "No se pudo conectar al servidor de señalización"

  • Verifica que el servidor Node.js esté corriendo: npm run dev
  • Asegúrate de que el puerto 3000 no esté bloqueado por el cortafuegos.
  • Comprueba que estás usando la IP correcta del servidor, no localhost desde otro dispositivo.

❌ El video no aparece en el receptor

  • Confirma que ambos dispositivos están en la misma red.
  • Los servidores STUN requieren acceso a internet para funcionar. Si estás en una red corporativa con proxy, pueden estar bloqueados.
  • Prueba reiniciando la conexión: desconecta y vuelve a conectar en ambos lados.

❌ El análisis de IA no funciona

  • Verifica que la variable ANTHROPIC_API_KEY esté definida en el archivo .env.
  • Revisa los logs del servidor en la terminal para ver el error exacto.
  • Asegúrate de que la captura de pantalla esté activa antes de activar el análisis.

❌ Captura de pantalla no disponible

  • Usa Chrome 72+, Edge 79+ o Firefox 66+ en escritorio.
  • La API de captura de pantalla solo funciona en HTTPS o localhost. Si accedes desde otro dispositivo, necesitas un certificado SSL o usar un túnel como ngrok.
🔒 HTTPS requerido en producción: Para usar getDisplayMedia() desde un dominio real (no localhost), el sitio debe servirse sobre HTTPS. Durante el desarrollo en red local, puedes usar ngrok para obtener una URL HTTPS temporal.
